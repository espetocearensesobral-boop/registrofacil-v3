# Evidências visuais — preenchimento dos botões

As capturas recebidas mostram que os botões **Processos**, **Dashboard** e **Métricas** aparecem com fundo branco ou quase branco, borda cinza e texto escuro. O problema ocorre no estado normal, antes do hover, e indica que o sistema está usando a superfície do cartão como fundo em vez de uma cor de ação preenchida.

A correção deve aplicar preenchimento temático padrão aos botões de navegação e ações auxiliares, mantendo texto com contraste suficiente. O hover não deve ser o único estado colorido.
