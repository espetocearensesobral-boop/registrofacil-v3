Bem-vindo ao Registro Fácil

Sistema completo para gerenciamento de processos, titulares e documentos. Este manual cobre todas as funcionalidades da versão atual.

O que é o Registro Fácil?

O Registro Fácil é um sistema web voltado para cartórios, escritórios e instituições que gerenciam grande volume de processos e documentos. Oferece ferramentas para registrar, acompanhar, auditar e gerar relatórios de cada processo de forma segura, com controle de acesso granular por usuário.

O sistema roda localmente na rede interna da empresa (sem necessidade de internet), com arquitetura cliente-servidor: um computador executa o servidor e todos os demais acessam pelo navegador.

Instalação e Acesso ao Sistema

Instalação via Instalador (.exe)

Execute o arquivo RegistroFacil_v3.27.0_Setup.exe como administrador e siga o assistente de instalação. O instalador:

  • Instala o sistema em C:\Program Files\Registro Facil\
  • Cria atalho na área de trabalho e no menu Iniciar
  • Cria os diretórios de dados em C:\ProgramData\RegistroFacil\
  • Registra o programa para desinstalação via Painel de Controle

Após a instalação, inicie o sistema pelo atalho criado. Uma janela de console aparecerá indicando que o servidor está ativo. Não feche esta janela enquanto o sistema estiver em uso.

Acessando o Sistema

No próprio servidor

Abra qualquer navegador moderno (Chrome, Firefox, Edge) e acesse:

http://localhost:5000

O sistema também abre o navegador automaticamente ao iniciar.

De outros computadores na rede

Descubra o IP do servidor: abra o Prompt de Comando (CMD) no servidor e digite ipconfig. Copie o Endereço IPv4 (ex: 192.168.1.10). Nos outros computadores, acesse:

http://192.168.1.10:5000

Firewall do Windows

Se outros computadores não acessarem o sistema, crie uma regra de entrada no Firewall do Windows para liberar a porta 5000 (TCP) no computador servidor.

Configurações técnicas do servidor

  • Servidor HTTP: Waitress 3.0 (multi-threaded, 8 threads)
  • Host: 0.0.0.0 (aceita conexões de qualquer IP na rede)
  • Porta padrão: 5000
  • Sessão: expira após 30 minutos de inatividade

Configuração Inicial (Para Administradores)

Credenciais de Primeiro Acesso

Usuário: admin   |   Senha: admin123

Importante: No primeiro acesso, o sistema exigirá a troca obrigatória da senha padrão antes de prosseguir.

Passos Recomendados após o Primeiro Acesso:

  1. Trocar a senha do administrador – exigido automaticamente no primeiro login.
  2. Configurar os dados da empresa – acesse Menu → Empresa e preencha nome, CNPJ, endereço e faça upload da logo. Ela aparecerá nos relatórios e PDFs gerados.
  3. Definir os Status de Processo – em Configurações → Status, crie os estágios do seu fluxo (ex: "Em Análise", "Com Exigência", "Concluído"), cada um com uma cor identificadora.
  4. Definir os Tipos de Serviço – em Configurações → Tipos de Serviço, cadastre as categorias de processos com seus prazos padrão em dias.
  5. Configurar o e-mail SMTP – em Configurações → E-mail, para habilitar recuperação de senha pelos usuários.
  6. Cadastrar usuários – em Administração → Usuários, crie contas para cada operador e defina suas permissões.
  7. Configurar o backup automático – em Configurações → Backup, defina pasta local e/ou servidor SFTP e o agendamento.

Criando um Novo Processo Alt+N

  1. Acesse o menu Processos → Novo Processo ou use o atalho Alt+N.
  2. Preencha os campos obrigatórios (marcados com *): Titular, Tipo de Serviço, Status e Prazo Final.
  3. Selecionar um Tipo de Serviço com prazo padrão preencherá o campo Prazo Final automaticamente.
  4. Para processos com matrícula, marque "Possui matrícula?" para exibir o campo correspondente.
  5. Arraste e solte arquivos na área de anexos ou clique para selecionar. O sistema valida tipo e tamanho antes do envio.
  6. Clique em Salvar. O titular será criado automaticamente nos Titulares caso ainda não exista.

Editando um Processo

Ao abrir um processo para edição, o sistema ativa um bloqueio de registro (Record Locking). Isso impede que dois usuários editem o mesmo processo simultaneamente, garantindo a integridade dos dados. Outros usuários verão um aviso informando quem está editando e poderão apenas visualizar.

O lock expira automaticamente após inatividade. Ao sair da tela de edição, o lock é liberado via AJAX.

Visualizando um Processo

A tela de visualização exibe todos os dados do processo, incluindo:

  • Dados principais com destaque visual para status e prazo.
  • Lista de Anexos com ícones por tipo de arquivo e opção de download.
  • Histórico de Alterações em formato de linha do tempo, registrando cada modificação com o usuário responsável, campo alterado, valor anterior e novo, e data/hora.

Anexos de Processos

O sistema aceita os seguintes tipos de arquivo como anexos:

PDF   DOC / DOCX   XLS / XLSX   CSV   TXT   JPG / JPEG   PNG   GIF

  • Tamanho máximo por arquivo: 50 MB
  • O tipo real do arquivo é validado via python-magic (análise de bytes), não apenas pela extensão.
  • Arquivos são armazenados em C:\ProgramData\RegistroFacil\uploads\processos\ com nomes UUID únicos para evitar conflitos.
  • O download exige autenticação — arquivos de processos não são acessíveis sem login.

Exportação e Relatórios

A partir das listagens de processos, é possível:

  • Exportar para Excel (.xlsx): Exporta todos os processos filtrados, com cores de status preservadas.
  • Imprimir lista: Gera uma página HTML formatada para impressão.
  • Gerar PDF da lista: Gera um PDF via WeasyPrint com a lista atual.
  • Relatório individual do processo: Na tela de visualização, é possível gerar relatórios em diferentes formatos para um processo específico.
  • Histórico impresso: Imprime o histórico de alterações de um processo.

Requer as permissões: processos_exportar, processos_pdf, processos_imprimir, processos_relatorio.

Controle completo sobre quem acessa o sistema e o que cada pessoa pode fazer.

Gerenciamento de Usuários

Acesse em Menu → Usuários. As ações disponíveis para administradores são:

  • Criar usuário: Defina nome, usuário, e-mail, senha e role. A senha pode ser marcada como "deve ser trocada no próximo login".
  • Editar usuário: Atualiza dados cadastrais.
  • Ativar / Desativar: Suspende o acesso sem excluir o cadastro.
  • Resetar senha: Gera nova senha temporária para o usuário.
  • Excluir usuário: Remoção definitiva (soft-delete).
  • Gerenciar permissões: Concede ou revoga permissões individuais.
  • Atribuir perfil de permissão: Aplica um conjunto pré-configurado de permissões.

Todas as ações administrativas sobre usuários são registradas na tabela auditoria_admin, incluindo campo alterado, valor anterior/novo e justificativa.

Módulo: Auditoria e Logs

O sistema registra todas as ações relevantes em múltiplas camadas, garantindo rastreabilidade completa.

1. Histórico de Alterações de Processos

Armazenado permanentemente no banco de dados. Visível na tela de Visualizar Processo, em formato de linha do tempo. Registra:

  • Criação do processo
  • Edição de qualquer campo (campo alterado, valor anterior, valor novo)
  • Adição e remoção de anexos
  • Usuário responsável pela ação e data/hora

Requer: processos_historico

2. Log de Atividades Gerais

Acessível em Menu → Atividades (Alt+A). Exibe um histórico paginado com filtros por usuário, tipo de ação e data. Registra:

  • Logins e logouts (com sucesso ou falha)
  • Criação, edição e inativação de usuários
  • Geração de backups e exportações
  • Acesso às principais seções do sistema

Exportável para Excel. Requer: atividades_visualizar / atividades_exportar

3. Logs por Domínio (Arquivos de Texto)

O sistema mantém arquivos de log diários segregados por domínio em C:\ProgramData\RegistroFacil\logs\:

DomínioPastaConteúdo
authlogs/auth/Autenticação, logins, tentativas bloqueadas
operacionallogs/operacional/Operações de processos e titulares
sistemalogs/sistema/Inicialização, scheduler, configurações
manutencaologs/manutencao/Backups, limpezas automáticas, migrações

Os logs antigos são limpos automaticamente a cada 90 dias (job agendado para 03:00 diariamente).

4. Auditoria Administrativa

Tabela auditoria_admin no banco de dados registra todas as ações administrativas sobre usuários, incluindo:

  • Quem fez a ação (admin), quem foi afetado (usuário alvo)
  • Campo alterado, valor anterior e novo
  • Justificativa (quando exigida pela ação)
  • IP e User-Agent do administrador

Módulo: Backup

Acesso via Alt+B. Garante a segurança dos dados com backup local e/ou em nuvem via SFTP.

Backup Manual

Qualquer administrador com a permissão backup_criar pode gerar um backup completo a qualquer momento. O arquivo gerado é um .zip contendo:

  • Uma cópia segura do banco de dados (registrofacil.db)
  • Todos os arquivos de upload vinculados aos processos

Os arquivos gerados ficam listados na tela com opções de download e exclusão.

Backup Automático (Scheduler)

Configure em Configurações → Backup. O agendador (APScheduler) executa em background no fuso horário America/Fortaleza.

OpçãoDetalhes
FrequênciaDiária, Semanal (dias específicos) ou Mensal (dia do mês)
HorárioQualquer hora (padrão: 02:00)
Destino localPasta configurável no servidor (padrão: C:\ProgramData\RegistroFacil\backups\)
Destino SFTPServidor remoto via SSH/SFTP (host, porta, usuário, senha, caminho)

Ferramentas do Banco de Dados

Disponíveis na página de Backup para administradores:

  • Testar integridade do banco: Executa PRAGMA integrity_check no SQLite.
  • Otimizar banco (VACUUM): Libera espaço e desfragmenta o banco de dados.
  • Reparar banco: Tenta corrigir inconsistências detectadas.

Estratégia de Restauração

Para restaurar um backup:

  1. Encerre o sistema (feche a janela do servidor).
  2. Extraia o arquivo .zip de backup.
  3. Substitua o arquivo C:\ProgramData\RegistroFacil\registrofacil.db pelo banco contido no backup.
  4. Substitua o conteúdo de C:\ProgramData\RegistroFacil\uploads\ pelos uploads do backup.
  5. Reinicie o sistema.
Atenção: A restauração substitui todos os dados atuais pelos dados do backup. Faça sempre um backup do estado atual antes de restaurar.

Segurança

O sistema implementa múltiplas camadas de proteção.

Autenticação e Sessão

  • Senhas criptografadas com bcrypt.
  • Sessão expira após 30 minutos de inatividade.
  • Troca de senha obrigatória no primeiro login (ou quando definido pelo admin).
  • Bloqueio por tentativas: Após 5 tentativas falhas consecutivas, o IP é bloqueado temporariamente.
  • Recuperação de senha por e-mail com token temporário (requer SMTP configurado).

Proteção de Formulários

  • CSRF Token em todos os formulários POST.
  • Sanitização de inputs (proteger_input()) em todos os campos de texto.
  • Cookies de sessão: HttpOnly e SameSite=Lax.

Validação de Arquivos

  • Tipo real do arquivo validado via python-magic (análise dos bytes do arquivo, não apenas a extensão).
  • Lista de tipos permitidos restrita (pdf, doc/docx, xls/xlsx, csv, txt, jpg/png/gif).
  • Tamanho máximo de 25 MB por arquivo.
  • Nomes de arquivo gerados com UUID para evitar colisões e path traversal.

Proteção de Banco de Dados

  • Lock de arquivo: Ao iniciar, o sistema adquire um lock no arquivo .db para evitar corrupção por acesso concorrente.
  • Chave secreta persistente: A SECRET_KEY do Flask é gerada uma vez e salva em arquivo oculto (.secret_key), evitando invalidação de sessões a cada reinício.
  • Todas as queries usam parâmetros parametrizados (proteção contra SQL Injection).

Controle de Acesso a Arquivos de Upload

  • Arquivos de processos e perfil exigem autenticação para download.
  • Arquivos de empresa (logo) são públicos (necessário para exibição nas páginas de login).
